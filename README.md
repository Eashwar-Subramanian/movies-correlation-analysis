# Movies Correlation Analysis (Python)

Exploratory data analysis in a Jupyter notebook to examine correlations between movie attributes, with a focus on budget vs gross revenue.

## What’s in this repo
- `Movies Correlation EDA Project.ipynb` — notebook with EDA + correlation analysis + visuals
- `movies.csv.zip` — dataset archive used by the notebook
- `README.md` — this document

## How to run
1) Ensure `movies.csv.zip` is present in the repo folder
2) Open and run:
   - `Movies Correlation EDA Project.ipynb`

## What the notebook covers
- Dataset loading and sanity checks
- Cleaning and type handling for analysis-ready columns
- Correlation analysis across numeric attributes
- Visual exploration of budget vs gross and other relationships
